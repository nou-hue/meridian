# meridian

A mission-day desk for an analog commander.

Open it and see sleep, open conflict, comms delay, and the one decision due before the next contact. Synthetic habitat only. No chatbot, no diagnosis, no rocket.

This is the same object as a clinical reasoning desk, pointed at a crew in confinement instead of a case in a clinic. Evidence stays evidence. The decision stays with the commander.

## Run

Open `index.html`, or serve the folder:

```bash
python3 -m http.server 4173
```

## Boundary

- Not a medical device.
- Not a crew-selection tool.
- Sleep figures are reported hours, not a clinical score.
- Conflict items are commander-authored operational tensions, not psychological findings.
- The habitat, crew, and sols are fictional.
